单文件夹处理

选择一个图集文件夹（内含散图），把该文件夹下所有图片打包成一个图集（自动分页）。
可预览、可设置打包参数与导出格式。

进入单文件夹处理 →
🗂️

多文件夹处理

选择一个根目录，其下每个子文件夹各自是一个独立图集源。一次性把所有子图集目录全部打包并输出到目标文件夹。

进入多文件夹处理 →

使用提示

  • 输入路径：填写服务器本机磁盘路径，可直接把文件夹拖到输入框自动识别。
  • 支持格式：png / jpg / gif / bmp / webp / tga。
  • 输出格式：通用格式（.atlas.txt）或 PixiJS v8（.atlas.json），每页一张 PNG。
  • 多文件夹模式：每个子文件夹生成一组图集，文件前缀 = 子文件夹名，全部输出到同一个输出文件夹。
