KTexturePacker

图集打包 · 基于 ASP.NET Core + MaxRects
本地模式适用于浏览器与服务器在同一台机器；路径是服务器（本机）磁盘路径。可直接把文件夹拖到输入框自动识别。
把图片或文件夹拖到这里
支持递归读取整个文件夹里的图片（png/jpg/gif/bmp/webp/tga）
远程模式适用於服务器在远端：图片会先上传到服务器再打包，不依赖本机路径。
